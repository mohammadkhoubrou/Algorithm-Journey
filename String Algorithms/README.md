## Strings
Strings are one of the fundamental data types in computer science. They store character strings, however we can store integers or
float point values too. Strings behave like lists and we can perform a number of similar operations on them just like lists.
For instance, each character in a string has its own index, starting from 0 for the first element untill n-1 where n is the length
of the string (Negative indexes, correspond to elements in reverse order). Meaning, it can be acessed individually. Additonally, it's possible 
to iterate over a string just like a list.
```
String:   P   Y   T   H   O   N
         +---+---+---+---+---+---+
         | P | Y | T | H | O | N |
         +---+---+---+---+---+---+
Index:     0   1   2   3   4   5

Negative: -6  -5  -4  -3  -2  -1
```
