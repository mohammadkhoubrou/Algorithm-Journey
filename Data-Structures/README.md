# **Data Structures**

Data structures play a crucial role in efficient programming. Data structures are ways of organizing the data to treat them efficiently. Each data structure includes descriptions of possible values an object can take on, certain operations performed on the object and behaviours of these operations. These descriptions are known as *abstract types* or *specifications*.

We can implement abstract data types using one or more different data structures(We must keep an eye on the description of the data type we use). It is possible to determine the complexity of each implementation. Thus, we can choose which implementation to use based on the task or problem we're trying to solve.

In order to write a good program, one of the most important things is to understand the mechanism of data structures offered by the language.
